# 突变签名分析：原理、结果影响因素与 spectrum 模块扩展（技术讨论稿 v0.1）

> **定位**：为 `modules/spectrum` 扩展「已知签名比较」与「NMF de novo 分解」提供原理背景与设计依据。
> **适用物种**：人类（GRCh37/38）与小鼠（mm10/mm39）。
> **事实核对**：2026-11-11 核对 COSMIC Mutational Signatures 官网（当前版本 v3.6；SBS 页面收录 101 个签名条目，编号至 SBS113 含 a-d 亚型；官方说明参考签名主要由 SigProfiler 从 PCAWG 2,780 个 WGS 中提取，另在 1,865 WGS + 19,184 WES 上评估稳定性）。COSMIC 数值签名文件需注册后从下载页获取，本模块只在 config 中引用用户提供的路径。
> **配套现状**：本模块当前 `bin/spectrum.py` 只做 VCF → 三核苷酸谱（96 通道、嘧啶链归一化）→ group 聚合 → stacked bar / heatmap / CSV。无 per-sample 矩阵输出，无签名分析。本文是实现前的讨论文档，不含代码。

## 1. 表示层：SBS96 三核苷酸谱

### 1.1 为什么是 96 个通道

点突变按替换类型有 4×4 = 16 种（A>C、A>G、…、T>G），但 DNA 是双链：

- 一条链上的 `A>G` 与互补链上的 `T>C` 是**同一个生化事件**的两种观察角度；
- 若不归一化，同一个突变过程会被拆成两套镜像通道，NMF 会把它们学成两个"签名"。

因此按**嘧啶链归一化**（ref 为 C 或 T，否则取反向互补），16 种替换折叠为 6 类：

```
C>A  C>G  C>T  T>A  T>C  T>G
```

再乘以突变位点 5' 侧翼 4 种 × 3' 侧翼 4 种 = 16 种三核苷酸上下文，得 **6 × 16 = 96 个通道**。这就是 COSMIC SBS 签名的标准表示。

为什么侧翼只取 ±1 bp：DNA 损伤与修复的序列偏好主要体现在紧邻位点（如 5mC 脱氨的 `NpCpG`、APOBEC 的 `TCA`）；更长的上下文（五核苷酸 1536 通道）能解析更多过程，但样本量需求急剧上升，96 通道是分辨率与统计功效的平衡点。COSMIC 同时收录 DBS78（双碱基替换）和 ID83（插入缺失）签名，**本模块目前只覆盖 SBS**。

**与现有代码的核对**（`bin/spectrum.py::get_trinucleotide`）：嘧啶链归一化已正确实现；但两个小缺口：
1. 侧翼含 `N` 的上下文未过滤，会被计入 `N[C>T]A` 这类垃圾通道，应直接丢弃；
2. 只按 `ALT` 长度 = 1 过滤，多等位位点（`ALT` 含逗号）会被 `str.len()==1` 挡掉（碰巧正确），但 `REF` 长度 ≠ 1 的异常记录没有显式排除。

### 1.2 机会数（opportunity）：被低估的偏差源

观测到的通道计数 = 过程偏好 × **该上下文在被检测区域中出现的次数**（机会数）。

- 人类基因组三核苷酸频率并不均匀（CpG 相对匮乏且甲基化态分布不均）；小鼠与人类的三核苷酸组成不同；
- WES 捕获区的上下文组成 ≠ 全基因组，panel 更极端；
- 同一个突变过程，在人类 WGS、人类 WES、小鼠 WGS 里呈现的 96 谱**形状都不同**。

后果：跨样本（WGS vs WES）、跨物种（人 vs 鼠）比较谱之前，要么按机会数归一化（SigProfilerMatrixGenerator 按参考基因组三核苷酸频率做校正），要么保证所有样本来自同一区域集。忽略这一步，"签名差异"可能只是捕获区组成差异。§5.5、§5.6 展开。

## 2. 生成模型：谱 = 签名 × 曝光

设 N 个样本、K 个突变过程：

```
M (96 × N)  ≈  W (96 × K)  ·  H (K × N)
```

- `M`：观测计数矩阵（通道 × 样本）；
- `W` 的每一列是一个**签名**：96 维概率分布（列和 = 1），代表一个突变过程的"指纹"；
- `H` 的每一行是一个**曝光**：该过程在各样本贡献的突变数。

模型假设：各过程独立作用、贡献可加、每个突变可归因于单一过程。生物学上这对应"多个损伤/修复过程并行，各自在序列偏好上稳定"的图景——APOBEC 脱氨（SBS2/13）、紫外（SBS7a-d）、错配修复缺陷（SBS6/15）、衰老时钟样（SBS1/5）等都是这样的"指纹"。

注意 `W` 与 `H` 都未知时问题是非凸且**尺度/排列不唯一**的（`W` 列重排 + 对应 `H` 行重排、`W` 列缩放 × `H` 行反缩放是同一解），所以约束（非负、归一）与多次重启是必需的，不是可选项。

## 3. NMF 分解：从数据中"发现"签名

### 3.1 为什么用 NMF 而不是 PCA/ICA

- **非负性**：计数不能为负。PCA 的负载向量没有生物学解释；NMF 把数据约束在正象限，学到的 `W`、`H` 直接可读作"分布"和"贡献量"。
- **部件表示**：PCA 学的是全局正交基（互相抵消），NMF 倾向学出局部化、可叠加的"部件"，与"多个独立过程叠加"的生成模型同构。
- 代价：非凸、局部最优、解不唯一 → 靠多次随机重启 + 秩选择 + 稳定性评估来压制（§3.3）。

### 3.2 目标函数：KL 散度比 Frobenius 更合适

计数数据的自然噪声模型是多项式/泊松。Frobenius 范数 `||M − WH||²` 隐含高斯等方差假设，会系统性高权高计数通道、低估低计数通道的相对波动。KL 散度：

```
D_KL(M ‖ WH) = Σ_ij [ M_ij · log(M_ij / (WH)_ij) − M_ij + (WH)_ij ]
```

与泊松似然等价（至常数），是 SigProfilerExtractor（沿用 Brunet 2004 的乘性更新）与 `sklearn.decomposition.NMF(loss='kullback-leibler', solver='mu')` 的标准选择。乘性更新（Lee & Seung 2001）：

```
H ← H ⊙ ( Wᵀ · (M ⊘ WH) ) / (Wᵀ 1)
W ← W ⊙ ( (M ⊘ WH) · Hᵀ ) / (1 · Hᵀ)
```

（`⊘` 逐元素除法；每步后归一化 `W` 列并把尺度并入 `H`。）

### 3.3 秩 K 的选择：没有单一判据是够的

- **重构误差**随 K 单调下降，不能单独用来选 K；
- **cophenetic 系数**（Brunet 2004）：对 `H` 的样本层次聚类在不同 K 下的一致性，拐点指示真实 K；
- **稳定性**：bootstrap/多次重启得到的 `W` 之间的一致性；
- SigProfilerExtractor 的实际做法：对 K = 1..maxNMFIterances 逐个试分解，比较重构 + 稳定性，再把多次分解出的相似签名聚类合并成"共识签名"。

**选错 K 的后果**（为什么这是 §5 的一级因素）：
- K 偏大：噪声被学成伪签名。低突变负荷样本的随机波动是"稳定的假模式"，NMF 会忠实地把它提出来——文献里相当一部分"新签名"事后被证实是伪影（COSMIC 近年版本专门标注了一批 artifactual signatures，散布在 SBS43 之后的编号区间）；
- K 偏小：两个过程被平均成一个数据中并不存在的"混合签名"，曝光也跟着错。

### 3.4 可辨识性：需要多少样本和突变

NMF 分离 K 个过程的前提是各样本的混合比例 `H` 有足够变化：样本数太少或队列太同质时，`H` 的行高度相关，`W` 不可分。经验下限：de novo 提取一般需要 **≥ 20–50 个样本**、每样本数百到数千 SNV（视异质性），而 COSMIC 签名集是在 2,780 个 WGS 上才稳定提取的。样本少时的正确姿势是**只做 refitting**（§4），不做 de novo。

## 4. 与已知签名比较（refitting）

### 4.1 余弦相似度

```
cos(a, b) = (a · b) / (||a|| · ||b||)
```

为什么用余弦：96 维**方向**比较，对总量（突变负荷）不敏感，正是"过程指纹"要比较的东西。社区经验阈值：≥ 0.85–0.9 视为匹配，0.7–0.85 存疑，< 0.7 不匹配（各工具略有差异）。严格说签名是概率分布，也可用 KL/JS 散度，但 COSMIC 生态的惯例是余弦，工具间可比性优先。

### 4.2 曝光回归：NNLS / QP

已知 `W`（COSMIC 矩阵）求 `H`：

```
min_{H ≥ 0} ‖ m − W h ‖²     （每样本独立，可选 Σh = m 总量约束）
```

即非负最小二乘（NNLS）或等价的二次规划。要点：

- **必须非负**：否则回归会给出"负曝光"来抵消共线性（§4.3），无意义；
- **稀疏化/剪枝**：小曝光置 0（L1 惩罚或工具内置的迭代剪枝），否则噪声会摊给几乎全部签名；
- 工具差异主要在剪枝策略：SigProfilerAssignment（迭代重构优化 + 剪枝）、deconstructSigs（加权 NNLS + 相似性阈值）、MutationalPatterns（cosine 引导的相似性拟合）。同一数据不同工具曝光不同，多半来自这里。

### 4.3 共线性：refitting 最大的坑

COSMIC 签名**不是正交基**。强相关家族：

| 家族 | 成员 | 为什么相似 |
|---|---|---|
| 时钟样 | SBS1, SBS5, SBS40(a/b/c, v3.6 已拆分) | 平坦/近平坦谱，随年龄累积 |
| APOBEC | SBS2, SBS13 | 同一酶家族的 C>T / C>G 两种产物，常成对出现 |
| MMR | SBS6, SBS15, SBS20, SBS26, SBS44 | 同一缺陷的不同谱面 |
| POLE/POLD1 | SBS10a-d, SBS14 | 校对缺陷 + 偶发 MMR 缺陷叠加 |

症状：同一数据不同工具给出不同曝光；曝光在家族成员之间"漂移"；低负荷样本尤甚。缓解：

1. 用工具默认的签名分组/剪枝规则，不要手工全库硬拟合；
2. 报告**家族级**曝光（如"APOBEC 家族 = SBS2+SBS13"），单签名数字只作参考；
3. 对强相关对（SBS2/13）合并解释是常规做法，不算妥协。

## 5. 结果的主要影响因素（核心章节）

### 5.1 每样本突变数 —— 影响最大的单一因素

**机制**：观测谱是真实谱的 n 次多项式采样，采样噪声使观测方向偏离真实方向。对均匀谱（96 通道等概率），观测与真值的期望余弦有闭式近似：

```
E[cos] ≈ sqrt( n / (n + 96) )        （一般化：sqrt( S2 / (S2 + n) )，S2 = Σ λ_i² 为期望计数平方和）
```

**验证**（本机 Monte Carlo，2000 次泊松采样，2026-11-11）：

| n（SNV 数） | 均匀谱实测 cos | 理论 sqrt(n/(n+96)) | 尖峰谱实测 cos |
|---|---|---|---|
| 50 | 0.587 | 0.585 | — |
| 100 | 0.716 | 0.714 | 0.803 |
| 500 | 0.917 | 0.916 | — |
| 1,000 | 0.956 | 0.955 | 0.974 |
| 5,000 | 0.991 | 0.991 | — |
| 20,000 | 0.998 | 0.998 | 0.997 |

（尖峰谱 = 单通道期望为基线 10 倍，特征越集中抗噪越好，但结论不变。）

**读法**：n = 100 时，即使真实过程只有一个，观测谱与真值的余弦也只有 ~0.72——**低于任何合理的签名匹配阈值**。也就是说低负荷样本的单样本 refit 本质是拟合噪声：0.85 阈值在 n < 300–500 时几乎不可能由真实信号达到，要么误配要么漏配。这解释了为什么：

- group 聚合（当前模块做法）确实能救命——把组内突变加总提高 n；
- 但聚合换来的是丢失样本级曝光（§5.8）；
- 认真的低负荷分析需要贝叶斯先验/置信区间（重采样给出曝光的 CI），而不是裸 NNLS 点估计。

**缓解**：报告每样本 n 并在 n 低于阈值（建议 200–500，视签名区分度）时标注"曝光不可靠"；分组谱与样本谱并行输出；暴露 CI 用 bootstrap。

### 5.2 样本数与队列异质性

NMF 的可辨识性（§3.4）：样本少 → 签名不可分；队列过同质（同一癌种同一驱动）→ 混合比例无变化，同样不可分。反直觉但重要：**队列异质性是 de novo 提取的信息来源，不是需要消除的噪声**。缓解：跨癌种/跨处理合并提取，之后再按组拆解曝光。

### 5.3 变异检测与过滤质量

伪影有自己的"稳定指纹"，NMF 会把它们学成伪签名：

| 伪影 | 谱面 | 为什么 |
|---|---|---|
| FFPE 脱氨 | C>T 升高 | 甲醛损伤胞嘧啶，形似 clock/MMR |
| 8-oxoG（文库制备） | C>A 峰 | 氧化损伤发生在提取/打断环节，不在体内 |
| 流程特异 | 各异 | caller、去重、链偏倚处理不一致引入系统偏差 |
| germline 泄漏 | 平坦稀释 | 未过 PoN/群体频率的种系变异混入 |

其他环节：体细胞低 VAF 漏检（纯度低的样本突变被系统性少检 → 直接改写 `M`）；多等位/复杂位点的处理不一致。**缓解**：全队列统一 caller + 过滤参数；对 C>A 异常峰保持警惕；把提取谱与已知伪签名做余弦比对（"这个'新签名'是不是 SBS43 类伪影？"）。

### 5.4 参考基因组与上下文提取正确性

坐标系不一致（chr 前缀、hg19 vs hg38、mm10 vs mm39）会让上下文全盘错位；`N` 侧翼不过滤（当前代码缺口，§1.1）会污染通道。上下文提取错误的恶劣之处在于**系统性**——不是加噪声，而是把计数从正确的通道搬到错误的通道。缓解：单一参考版本贯穿全流程；提取前对参考 FASTA 与 VCF contig 命名做一致性校验；`N` 侧翼丢弃并记录丢弃计数。

### 5.5 WGS / WES / panel 与机会数

见 §1.2。特别提醒：COSMIC 签名是从 **WGS** 提取的。WES 数据直接与 COSMIC 比较而不做机会数校正，平坦签名（SBS5/40）和上下文不均匀的签名（SBS1 的 CpG 依赖）会系统性偏移。缓解：机会数归一化（按捕获区三核苷酸频率），或所有样本限制到同一靶区后比较；跨平台队列内比较比绝对签名注释更可靠。

### 5.6 物种：人类 vs 小鼠

- **保守的部分**：突变过程的序列偏好跨哺乳动物保守（APOBEC、UV、MMR、POLE 校对缺陷等的谱形相似），强特征签名做跨物种比较有参考价值；
- **不保守的部分**：基因组三核苷酸机会数不同（§1.2），平坦 clock-like 签名（SBS5/40）本来特征就弱，跨物种拟合基本不可靠；
- **资源现状**：SigProfiler 系支持 mm10/mm39 参考；实验诱导签名可查 SIGNAL（signal.mutationalsignatures.com）；多哺乳动物种系/体细胞突变谱比较见 Cagan et al., Nature 2022。COSMIC 主库是人类签名。

**建议策略**：小鼠数据以 **de novo 提取为主**；与人类 COSMIC 签名的余弦比较作为**注释性输出**，报告中明确标注"跨物种参考，非同源赋值"。人类数据走标准 refit。

### 5.7 秩选择 K

§3.3 的机制在结果层的体现：K 错 → 签名与曝光全错，且错误形式是"自信的错误"（重构误差看起来很好）。缓解：rank 诊断（误差曲线 + cophenetic + 稳定性）必须随结果输出，让审阅者能自己判断 K；K 不确定时报告相邻 K 的结果对比。

### 5.8 聚合策略（当前模块的 group 聚合）

- **得**：组内突变加总 → n 变大 → 采样噪声下降（§5.1），适合"组的平均谱"这种粗粒度问题；
- **失**：样本级曝光消失、组内异质性被抹平、组间样本构成不均时引入混杂（一组 10 个高负荷样本 vs 一组 2 个，聚合谱完全不可比）；
- **为什么不能只聚合**：签名分析的核心问题（"哪个样本有哪些过程、各多少"）定义在样本级；聚合谱是样本级的下游派生物，不是替代品。

**建议**：per-sample 96 矩阵作为**基础输出**；分组谱、分组图全部从样本级派生；NMF 用样本级矩阵，曝光可再按组汇总展示。

### 5.9 治疗史与克隆结构

治疗会叠加"医疗签名"：替莫唑胺（SBS11）、铂类（SBS31/35）、放疗等（COSMIC 页面已确认 SBS11 etiology = temozolomide treatment）。克隆结构方面：低纯度稀释突变数（回到 §5.1）；亚克隆过程按突变比例被低估（早期克隆的过程看起来更强）；多灶/混合组织样本是天然的"多过程混合"，反而适合 NMF 但解释要小心。**缓解**：收集样本元数据（治疗史、纯度、取样部位）作为 `group-map` 的扩展列，结果按其分层。

### 5.10 软件与参数

初始化、随机种子、收敛阈值、KL vs Frobenius（§3.2）、签名库版本（COSMIC 版本间签名集会变：v3.6 就拆分了 SBS40a/b/c、SBS22a/b/c）都会改变结果。**缓解**：版本与 seed 写入 receipt（模块已有该惯例）；de novo 用多次重启取共识；refit 固定一个 COSMIC 版本贯穿项目。

## 6. 对 spectrum 模块的落地含义

按依赖分层（细节待讨论后出实施方案，此处只定方向）：

| 层 | 内容 | 依赖 |
|---|---|---|
| P0 数据基础 | per-sample 96 矩阵 CSV；`N` 侧翼过滤；每样本突变数 n 统计 | 无，纯补输出 |
| P1 参考签名比较 | 输入用户提供的 COSMIC 数值文件（人/鼠分列，config 路径）；NNLS + 余弦 + 剪枝；家族级曝光报告；n 低于阈值样本标注 | P0 |
| P2 de novo NMF | sklearn NMF（KL + mu）多重启 + rank 诊断（误差/cophenetic/稳定性）；输出共识签名与曝光；与 COSMIC 的余弦注释 | P0；样本数 ≥ 20–50 才有意义 |
| 小鼠专项 | de novo 为主；与人类签名的 cosine 标注为"跨物种参考" | P1/P2 |

输出物清单（P1/P2 共同）：每样本 96 谱 CSV、曝光矩阵（样本 × 签名）、签名-签名余弦热图、曝光堆叠图、rank 诊断图（P2）、每样本 n 与可靠性标注。

## 附：本文的数值验证

§5.1 的余弦表为本机 Monte Carlo 实测（2020 次泊松重采样，均匀谱与单峰谱），理论式 `E[cos] ≈ sqrt(S2/(S2+n))`（S2 = 期望计数平方和；均匀谱退化为 sqrt(n/(n+96))）与实测在所有 n 上吻合（差异 ≤ 0.004）。该式可直接用于评估"给定突变数下签名匹配的信噪上限"。
